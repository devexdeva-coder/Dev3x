ACTIVE DIRECTION — DEV3X ADAPTIVE LLM RUNTIME

Investigating how increasingly large language models could run on hardware with limited RAM/VRAM — instead of loading an entire model into memory, exploring layer streaming, memory mapping, asynchronous prefetching, adaptive scheduling, quantization, caching, and CPU/iGPU cooperation.

Model storage ↓ Layer loader ↓ Memory manager ↓ CPU / iGPU computation ↓ Cache / eviction ↓ Next layer

The question this is trying to answer: can adaptive weight streaming and memory-management techniques make significantly larger LLMs practical on memory-constrained consumer hardware, without an unacceptable performance or quality penalty?

Current status: this is a design-stage research direction. It is not yet a benchmarked, working system — treat any specific performance numbers as targets to measure against, not results.
